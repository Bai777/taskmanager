# 📋 Task Manager

Современный и высокопроизводительный сервис для управления задачами с комплексной **JWT-аутентификацией** и разделением прав доступа.

---

## 🛠 Технологический стек

* **Язык разработки:** Java 21
* **Фреймворк:** Spring Boot 3.4.3
* **Безопасность:** Spring Security, JWT (JSON Web Token)
* **База данных:** PostgreSQL 16
* **Контейнеризация:** Docker, Docker Compose
* **Мониторинг:** Micrometer (Prometheus), Spring Boot Actuator
* **Документация:** Swagger / OpenAPI 3 (SpringDoc)

---

## ⚙️ Конфигурация БД (по умолчанию)

Для работы приложения в локальном режиме используются следующие параметры подключения:

| Параметр | Значение по умолчанию |
| :--- | :--- |
| **URL подключения** | `jdbc:postgresql://localhost:5432/database_taskmanager` |
| **Пользователь** | `postgres` |
| **Пароль** | `admin` |

💡 **Важно:** Вы можете легко переопределить эти настройки в конфигурационном файле или через переменные окружения: `USER`, `PASSWORD`, `JWT_SECRET`, `JWT_EXPIRATION`.

## 🚀 Запуск и развертывание

### Вариант 1. Через Docker (Рекомендуется)
Убедитесь, что у вас установлен и запущен Docker Daemon. Выполните команду в терминале:
```bash
docker-compose up --build
```
> 🌐 Приложение автоматически развернется и будет доступно по адресу: **`http://localhost:8080`**

### Вариант 2. Локальный запуск (без Docker)
1. Установите **PostgreSQL 16**.
2. Создайте базу данных с именем `database_taskmanager`.
3. Убедитесь, что параметры доступа соответствуют `postgres`/`admin` (или скорректируйте их в файле `src/main/resources/application.yaml`).
4. Запустите приложение с помощью Maven:
```bash
mvn spring-boot:run
```

## 📖 Инструкция по использованию

### 1. Документация Swagger UI
Интерактивная спецификация API доступна в браузере сразу после запуска:
👉 **`http://localhost:8080/swagger-ui.html`**

### 2. Регистрация нового пользователя
* **Эндпоинт:** `POST /api/auth/register`
* **Тело запроса (JSON):**
```json
{
  "username": "user",
  "email": "user@test.com",
  "password": "password",
  "role": "USER"
}
```

### 3. Аутентификация и получение JWT-токена
* **Эндпоинт:** `POST /api/auth/login`
* **Тело запроса (JSON):**
```json
{
  "username": "user",
  "password": "password"
}
```
* **Ответ сервера:**
```json
{ 
  "token": "eyJhbGciOi..." 
}
```
📌 **Обязательно скопируйте** полученное значение `token` для последующих запросов.

### 4. Авторизация запросов в Swagger
1. Откройте Swagger UI и нажмите кнопку **Authorize** (иконка с замком) в правом верхнем углу страницы.
2. Вставьте скопированный JWT-токен в текстовое поле **Value**.
3. Нажмите кнопку **Authorize**, а затем **Close**.
4. Теперь все защищенные эндпоинты будут прозрачно выполняться от имени вашего авторизованного пользователя.

## 🛣 Карта REST API Эндпоинтов

| Метод | URL-путь | Разрешенные роли | Описание |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/auth/register` | **Все пользователи** | Регистрация нового аккаунта |
| `POST` | `/api/auth/login` | **Все пользователи** | Вход и генерация JWT |
| `GET` / `POST` | `/api/tasks/**` | `USER`, `ADMIN` | Просмотр и создание задач |
| `PUT` / `DELETE` | `/api/tasks/**` | `USER`, `ADMIN` | Обновление и удаление задач |
| `PATCH` | `/api/tasks/{id}/restore` | **Только** `ADMIN` | Восстановление удаленной задачи |
| `GET` / `DELETE` | `/api/admin/users/**` | **Только** `ADMIN` | Управление пользователями системы |
| `GET` | `/api/admin/tasks/**` | **Только** `ADMIN` | Глобальный аудит всех задач |

## 🧪 Тестирование и Сборка

### Запуск тестов
Проект покрыт интеграционными тестами. Обратите внимание, что они используют библиотеку **Testcontainers**, поэтому во время выполнения тестов **должен быть запущен Docker**.
```bash
mvn test
```

### Сборка артефакта
Для компиляции кода, запуска тестов и сборки готового `.jar` файла выполните:
```bash
mvn clean install
```
